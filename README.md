## 🧪 Sobre este proyecto

Este repositorio contiene ejercicios y prácticas personales orientados al aprendizaje y desarrollo de habilidades en QA Automation.

Actualmente incluye pruebas automatizadas de login utilizando Playwright y JavaScript.

### Casos de prueba automatizados

- Verificación del título de una página.
- Verificación de navegación mediante un enlace.
- Login correcto.
- Login con usuario y contraseña incorrectos.
- Login con campos vacíos.
- Login con contraseña vacía.

### Objetivos

- Aprender automatización de pruebas E2E.
- Diseñar y ejecutar casos de prueba.
- Validar funcionalidades de aplicaciones web.
- Identificar errores y analizar resultados.
- Familiarizarme con herramientas de automatización.
